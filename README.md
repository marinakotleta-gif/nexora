# NEXUS Telegram Mini App

Тап-игра в виде Telegram Mini App с сохранением прогресса в локальном хранилище браузера.

## Возможности
- нажатия и получение звездной пыли;
- улучшение силы нажатия;
- питомцы и пассивная добыча;
- задания с наградами;
- адаптация под Telegram WebApp;
- сохран��ние прогресса;
- экран профиля и сброс данных.

## Запуск
Откройте репозиторий через GitHub Pages или другой HTTPS-хостинг.

Для Telegram:
1. Создайте бота через @BotFather.
2. Введите `/newapp` и укажите HTTPS-адрес страницы.
3. Используйте домен без межсайтовых перенаправлений.

## Монетизация
Демонстрационные предметы используют внутриигровую валюту и не принимают платежи.
Для платежей Telegram Stars нужен бот-сервер с API-секретом и обработчиками invoice и successful_payment. Ключи Telegram нельзя хранить в этом файле или в браузерном коде.
